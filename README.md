# 🐱🐶 Cat vs Dog Detection Using CNN

## 📌 Overview

This project uses a **Convolutional Neural Network (CNN)** to classify images into two categories: **Cat** and **Dog**.

The CNN learns visual features such as edges, shapes, textures, and patterns from images and uses these features to predict whether a new image contains a cat or a dog.

---

## 🎯 Objective

The main objective of this project is to build an image classification model that can:

- 🐱 Identify cats
- 🐶 Identify dogs
- Process and resize input images
- Learn image features using CNN layers
- Predict the class of new images

---
